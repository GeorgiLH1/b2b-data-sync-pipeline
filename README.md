# AI Powered B2B Data Sync Pipeline
This project is and AI powered business to business data sync web program. It is able to synchronize, clean, sort, describe the data of 2 databases using AI.
Its aim is to make working between businesses easier and faster with less mistakes.
## Status
Work in progress.

### Planned Features
Synchronize data
Simplify data
Clean databases
Save time
Find mistakes
Give descriptions
User frendly UI
